# Design Context — CompSynth

## Users

Researchers, engineers, and technically-minded readers who track Chinese-language technical blogs and publications. They arrive to triage a day's worth of feeds, quickly separate signal from noise, and leave with a curated understanding. The tool will be shared publicly (open-source or published digests), so the interface must feel polished and credible to first-time visitors, not just its creator.

Primary use case: morning or end-of-day scan — open the inbox, skim topic clusters, read a few articles, check the digest. Speed matters, but so does the feeling of reading something well-edited.

## Brand Personality

**Calm, precise, editorial.**

Three concrete words: **measured, authoritative, unhurried**.

The interface should feel like opening a well-edited Sunday newspaper or a research journal's table of contents — information-dense but not overwhelming, every element placed with intention. Not a dashboard. Not a terminal. An editor's desk.

Emotional goals:
- Confidence: "I can trust what I see here is curated, not dumped."
- Clarity: "I immediately know what's new, what matters, and where to go."
- Calm: "This doesn't fight for my attention. It respects my time."

## Aesthetic Direction

**Editorial/magazine with bilingual typographic sensitivity.**

Visual tone: Clean, spacious, type-driven. The content IS the design. Typography and spacing do the heavy lifting — not color, not decoration, not illustration. Think of how The New York Times or Monocle use restraint as a style.

Theme: Both light and dark, following system preference. Light as the default primary (matching the editorial/reading context). Dark mode for extended evening reading sessions.

References (directional, not literal):
- The quiet confidence of a well-set broadsheet: generous margins, strong type hierarchy, no visual noise
- Research journal table-of-contents pages: dense but scannable, information-first
- Japanese editorial design sensibility: attention to grid, negative space, and bilingual type harmony

Anti-references:
- Generic SaaS dashboards with card grids and metric widgets
- "AI-generated" aesthetics: glassmorphism, gradient text, cyan-on-dark, glowing accents
- Developer tools with monospace-everything aesthetics
- Social media feeds with engagement-driving UI patterns

## Design Principles

1. **Typography first.** Type hierarchy, weight, and spacing carry the visual identity. Choose fonts that honor both Latin and Chinese text equally — a refined Latin display face paired with a CJK body face that share structural DNA.

2. **Restraint as style.** Every decorative element must justify itself. If removing it makes the page clearer, remove it. White space is not wasted — it's editorial voice.

3. **Hierarchy through weight, not color.** Use size, weight, and proximity to create visual priority. Color is reserved for semantic meaning (status, interactivity) and sparing accent, not for attention.

4. **Bilingual harmony.** The interface mixes English UI labels with Chinese content. Design the type system so both languages feel native, not like one is a fallback. Match x-heights, line heights, and weight perception across scripts.

5. **Quiet authority.** The interface doesn't shout. It doesn't use animation to impress. It earns attention through clarity and craft — the kind of design that gets better the longer you look at it.
